# Internship-Market-Analysis-Using-Web-scraping-EDA


## 📌 Project Overview

This project analyzes internship listings collected from Internshala using Python web scraping and data analysis techniques. The aim is to understand internship trends and help students compare opportunities.

## 🎯 Objectives

* Collect internship data using web scraping.
* Clean and analyze the collected data.
* Identify popular internship locations and skills.
* Analyze stipends and internship durations.
* Compare companies and work modes.
* Find useful insights through charts and statistical tests.

## 🛠️ Tools Used

* Python
* Selenium
* BeautifulSoup
* Pandas and NumPy
* Matplotlib and Seaborn
* SciPy
* Jupyter Notebook

## 📊 Analysis Performed

* Internship locations
* Frequently requested skills
* Work mode distribution
* Stipend analysis and outliers
* Internship duration analysis
* Company-wise internship listings
* Stipend comparison across companies
* Statistical hypothesis testing

## 💡 Key Insights

* Mumbai had the highest number of listings in the collected dataset, followed by Bangalore.
* Communication and English proficiency were frequently mentioned skills.
* Three-month and six-month internships were common.
* Stipends varied across internship listings and companies.
* The analysis explored the relationship between stipend and internship duration.
